# Miranto Zaenal Arief · Portfolio

A bilingual (EN/ID) scroll-driven portfolio, built with the scroll-craft skill.

Live: https://zaenalariefrl-glitch.github.io/miranto-zaenal-arief/

- `index.html` (English) and `id/index.html` (Indonesian): generated pages, do not edit by hand
- `src/portfolio.html`: the bilingual source; run `python3 tools/build_pages.py` after editing it
- `robots.txt`, `sitemap.xml`, `assets/og-image.jpg`: search and link-preview files
- `scrollcraft.js`, `scrollcraft.css`: scroll engine (MIT, nateherkai/scroll-craft)
- `assets/`: photos, certificates, and an original bossa nova loop
- `scrollcraft/builds/portfolio/BRIEF.md`: design brief
